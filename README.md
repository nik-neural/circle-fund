# 💰 圓子基金

群組消費記帳 + 圓子基金 — 朋友之間輕鬆分帳。

> **官方原始碼：** [github.com/nik-neural/circle-fund](https://github.com/nik-neural/circle-fund)

## 功能

- 多人活動記帳，自動計算每人應付 / 應收
- 圓子基金共同錢包，支援墊支同結算轉入
- 建議還款方案 + WhatsApp 分享
- 活動匯出 / 匯入，方便同朋友同步

## 加入主畫面（PWA）

1. 用手機或電腦開啟上方連結
2. **Safari / Chrome** → 分享 / 選單 → **加入主畫面**

## 技術

- 單一 HTML · Tailwind CDN · 零後端
- UI：iOS 風格 **Liquid Glass**（emerald 主色；半透明導航、玻璃卡片、膠囊按鈕）
- 全局「圓子基金」共同錢包（跨活動共享）
- [GitHub Pages](https://pages.github.com/) 部署
- PWA（`manifest.json` + `icons/`）
- 資料儲存喺瀏覽器 localStorage，唔会上傳伺服器
