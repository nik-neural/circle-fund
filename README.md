# 💰 圓子基金

群組消費記帳 + 圓子基金 — 朋友之間輕鬆分帳。

[![開啟 Web App](https://img.shields.io/badge/開啟-Web_App-10b981?style=for-the-badge)](https://nik-neural.github.io/circle-fund/)

## 功能

- 多人活動記帳，自動計算每人應付 / 應收
- 圓子基金共同錢包，支援墊支同結算轉入
- 建議還款方案 + WhatsApp 分享
- 活動匯出 / 匯入，方便同朋友同步

## 加入主畫面（PWA）

1. 用手機或電腦開啟上方連結
2. **Safari / Chrome** → 分享 / 選單 → **加入主畫面**
